## Troubleshooting

### Authentication Issues

If you see authentication errors:

```bash
# Remove old token and re-authenticate
rm credentials/youtube_token.pickle
python scripts/youtube_uploader.py [parameters]
```

This will open a browser for OAuth authentication.

### Upload Failures

If upload fails:
- Check internet connection
- Verify video file exists and isn't corrupted
- Ensure sufficient YouTube quota (10,000 units per day)
- Try again with longer timeout

### Quota Limits

YouTube API has daily quota limits:
- Each upload costs ~1,600 units
- Daily quota: 10,000 units
- You can upload ~6 videos per day
- Quota resets at midnight Pacific Time

**Recommendation**: Upload 1-2 episodes per day to stay within limits and allow time for review.
